# THE CHEFZ — Working Hours Update Site

Desktop-first landing page based on the provided THE CHEFZ design reference.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Poppins + Cairo

## Brand colors
- Dark Purple: #3D1A3D
- Orange: #EF5B16
- Secondary Purple: #755375
- White: #FFFFFF

## Run locally
Open `index.html` in Visual Studio Code using Live Server, or open it directly in a browser.

## Links
Edit the `LINKS` object in `script.js` to add:
- Inform Us with New WHs URL
- Learn How to Change WHs URL
- WhatsApp URL
- Email address

## Note
The mobile layout is intentionally not finalized yet. This version is the desktop build.
